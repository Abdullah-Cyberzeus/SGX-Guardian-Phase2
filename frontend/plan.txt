# Feature Request: Enterprise Live Attack Topology Visualization

## Objective

Design and implement a world-class **Live Attack Topology Visualization** for the Guardian Admin Console that transforms real-time Suricata alerts into an interactive cyber-physical attack map.

The experience should resemble premium SOC platforms such as **Microsoft Defender XDR, Palo Alto Cortex XDR, CrowdStrike Falcon, Dragos, Nozomi Networks, Claroty, and Splunk Enterprise Security**, with smooth animations, modern UI, and highly interactive network visualization.

---

# Primary Goal

Replace static alert monitoring with a **living digital twin** of the OT/ICS environment where analysts can instantly understand:

- Attack origin
- Attack destination
- Attack path
- Guardian protection status
- PLC/Sensor health
- Device relationships
- Threat propagation
- Real-time network activity

The visualization should feel alive even when no attacks are occurring.

---

# New Navigation

Add a new tab on the Alerts page.

```
Alerts
│
├── Alert List
├── Live Attack Topology
└── (Future) Attack Timeline
```
